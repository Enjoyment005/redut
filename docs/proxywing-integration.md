# ProxyWing: каталог, покупка и продление

Актуально для Редута 1.13.5, 8 сентября 2026 года.

## Каталог и ручные операции

В разделе «Деньги» одна форма выбранного провайдера. Каталог загружается при открытии;
смена типа, страны, локации или количества использует уже полученные предложения.
Кнопка «Обновить» запрашивает каталог заново.

Доступны ровно два типа: **Датацентр IPv4** и **ISP прокси**. Страны берутся только
из предложений выбранного типа. Для ISP учитываются конкретная страна и количество
из названия товара API, например `1 Proxy ISP US`. Региональный пакет без установленной
страны не превращается в список всех стран. Локация показывается при наличии вариантов.

Покупка: выбрать тип → страну → нажать кнопку с полной ценой пакета. Отдельного
USD-бюджета и повторного подтверждения нет. Сервер проверяет актуальный товар,
цену, валюту, баланс и исправность журнала перед оплатой. Ручная покупка импортирует
новые IP с ролью `off`; владелец выбирает их использование в пуле.

Новые заказы покупаются на календарный месяц по `price_monthly`. Более длинные
циклы покупки не предлагаются без документированной точной цены. Продление
существующего месячного заказа доступно на **1/3/6/12 месяцев** по `renewal-options`.
Кнопка «Продлить» у IP предлагает срок и точную цену; оплачивается весь заказ,
а новый срок записывается для всех его локальных IP. Каталог покупки для этого не нужен.

## Автоматика

При включённом `auto_prolong.enabled` продлевается здоровое текущее подключение.
Пул сопоставляется по полному адресу подключения, включая протокол, порт и учётные
данные. Перед оплатой повторно проверяются действующий канал, здоровье и свежая дата
заказа у провайдера. Порог `days_before` по умолчанию — 3 дня; срок
`proxywing_months` — 1 месяц (допустимы 1/3/6/12). Отдельные запасные заказы не продлеваются.
Разрешение новых покупок и старый `proxywing_money` не блокируют это автопродление.

При разрешённых автоматических покупках ProxyWing участвует в пополнении пула
и создании резерва вместе с PROXY6 и ProxyLine. Выбор учитывает фактические предложения,
стратегию, запрещённые страны и историю стабильности этого провайдера. Перед покупкой
повторно проверяются наличие подходящего резерва, ручная фиксация и актуальность задания.
Новые IP проверяются перед включением в резерв. Оплаченный исправный резерв сохраняется
при смене стратегии; старое задание не переключает вручную закреплённый канал.

## Оплата и восстановление

Точный запрос сохраняется в SQLite до отправки. С его постоянным `Idempotency-Key`
связаны операция, семейство, товар/заказ, срок, предел цены и отпечаток аккаунта.
Смена параметров или API-ключа не позволяет отправить старый запрос в другой аккаунт.
Подтверждённый ответ сохраняется до обновления финансового журнала и пула.

Фоновое восстановление читает сохранённый ответ и загружает оплаченные IP без новой
оплаты. Неизвестная отправка блокирует новый платёж, включая покупку у другого провайдера.
Явное ручное завершение прежней операции использует тот же запрос и ключ, повторно
проверяя параметры. Автоматика не повторяет неизвестный денежный POST другим транспортом.

`awaiting_payment`, неполный или несоответствующий ответ не объявляется успехом.
API не предоставляет поиск результата по ключу; угадывать оплату по балансу или списку
счетов нельзя. Не удаляйте историю ради повторной оплаты. При недоступном sessionStorage
исходный запрос сохраняется в памяти вкладки; до сверки такую вкладку следует сохранить.
Безопасный режим конфигурации и неисправный денежный журнал блокируют новую отправку.

## Контракт и проверки

- [Общий API: Bearer и Idempotency-Key](https://proxywing.com/documentation/api).
- [Datacenter: products, orders, renewal-options, extend, proxies](https://proxywing.com/documentation/api/datacenter).
- [ISP: products, orders, renewal-options, extend, proxies](https://proxywing.com/documentation/api/isp).

Используются JSON и существующие прямой/tun0 транспорты. Residential, Mobile,
покупка трафика и изменение whitelist в этот поток не входят.

Тесты проверяют единый каталог, страны ISP, полную цену пакета, потерю ответа,
обновление всех IP заказа, смену аккаунта/канала/стратегии и отсутствие повторной оплаты.
Ручной поток ранее принят владельцем на VADIM. Полная версия 1.13.5 выпускается
без серверной приёмки итоговой автоматики; реальные траты для её тестирования не выполнялись.
