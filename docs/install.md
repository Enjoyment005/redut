# Установка и первые шаги

## Что понадобится

| | |
|---|---|
| Сервер | VPS у российского хостера: 1 vCPU, 1 ГБ RAM, 10 ГБ диска, **чистая Debian 13**, root-доступ по SSH |
| Устройства | бесплатное приложение WireGuard (App Store, Google Play, Windows, macOS, Linux) |
| Аккаунт прокси-сервиса | нужен для динамических каналов — см. ниже. Без него туннель тоже работает, но канал будет один и постоянный |
| Ваш компьютер | ничего, если ставите одной командой на сервере; Python 3.9+ и `paramiko` — если через оркестратор |

### Аккаунт для исходящих каналов

Узел берёт адреса по API, поэтому нужен аккаунт у сервиса аренды прокси. Рекомендуем те, с
которыми работаем:

| Сервис | Ссылка | Промокод | Скидка |
|---|---|---|---|
| **PROXY6** (основной: рубли, покупка и продление прямо из панели) | [proxy6.net](https://proxy6.net) | `red12` | 5% пожизненно |
| **ProxyLine** (как второй источник) | [proxyline.net](https://proxyline.net) | `red12` | 10% |

Зарегистрируйтесь, пополните баланс с промокодом `red12`, скопируйте API-ключ из кабинета —
он понадобится на третьем шаге мастера. Ключ можно ввести и позже, узел будет работать и без него.

Почему именно российский хостер — [отдельный документ](why-russian-server.md).

## Шаг 1. Одна команда на сервере

Зайдите на сервер по SSH под root и вставьте:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Enjoyment005/redut/main/setup.sh)
```

Параметры задаются переменными окружения перед командой:

```bash
NAME=home PANEL_PORT=9443 SUBNET=10.9.0.0/24 CLIENTS=phone,laptop \
  bash <(curl -fsSL https://raw.githubusercontent.com/Enjoyment005/redut/main/setup.sh)
```

* `CLIENTS` принимает список имён (`phone,laptop`), число (`3` → `client1..client3`) или
  пару `имя:адрес` (`phone:10.8.0.5`) — последнее нужно при переустановке поверх живого узла,
  чтобы у клиента не поменялся IP;
* `SRC_DIR=/path/to/repo` — поставить из уже скачанного репозитория, ничего не качая.

> Почему `bash <(curl …)`, а не `curl … | bash`: при пайпе у скрипта нет доступа к терминалу,
> и он не может ничего спросить или показать интерактивно. Такая форма — корректнее.

## Альтернатива: установка с рабочей машины

Если серверов несколько, удобнее оркестратор по SSH — тогда на вашем компьютере нужен
Python 3.9+ и `pip install paramiko`:

```bash
python install/bootstrap.py --host ВАШ_IP --pw ROOT_ПАРОЛЬ --name node1
```

Оба пути делают одно и то же, примерно за 4 минуты:

1. определит сетевые параметры сервера (шлюз, интерфейс, внешний адрес);
2. поставит пакеты, WireGuard и sing-box фиксированной версии;
3. сгенерирует ключи сервера и первого клиента;
4. настроит маршрутизацию и правила, которые переживают перезагрузку;
5. развернёт панель управления с самоподписанным сертификатом;
6. заберёт готовый клиентский профиль к вам в `install/clients/<имя>/`;
7. напечатает отчёт проверки.

Полезные ключи:

```bash
--clients 3                 # сразу три профиля: client1..client3
--clients phone,laptop      # или с понятными именами
--subnet 10.9.0.0/24        # своя клиентская подсеть
--panel-port 9443           # другой порт панели
--no-panel                  # только туннель, без веб-интерфейса
--dry-run                   # показать план и ничего не менять
```

## Повторный запуск: штатный способ обновиться

Ту же команду можно выполнять сколько угодно. Проверено на живом узле, что переустановка:

* **сохраняет устройства, заведённые через панель** — они не выпадают из конфигурации туннеля;
* **не сбрасывает исходящий канал**, выбранный вами или автоматикой (перебить его можно
  только явно — ключом `--upstream` у оркестратора);
* сохраняет учётную запись панели, ключи, лимиты и настройки из конфига;
* не задваивает правила файрвола, маршруты и задания планировщика.

## Шаг 2. Мастер первого входа

Откройте `https://ВАШ_IP:8443/setup`.

Браузер предупредит о самоподписанном сертификате — это ожидаемо. Сверьте отпечаток с тем,
что напечатал установщик, и продолжайте.

> ⚠️ **Первый вход не защищён паролем.** Панель занимает тот, кто открыл её первым, поэтому
> пройдите мастер сразу после установки.

Мастер займёт пару минут:

1. **Пароль** — лучше нажать «Сгенерировать» и сохранить результат в менеджер паролей.
2. **Двухфакторка** — отсканируйте QR приложением-аутентификатором (Google Authenticator,
   Aegis, 1Password) и сохраните резервные коды отдельно от телефона.
3. **Ключ прокси-сервиса** — вставьте API-ключ из кабинета (ссылки и промокоды выше). Панель
   проверит его сразу и покажет ваш баланс. Именно с этого момента работают динамические
   каналы: узел сам покупает, проверяет, продлевает и переключает адреса. Шаг можно
   пропустить и вернуться к нему позже — тогда канал останется один, заданный при установке.
4. **Почта для оповещений** — куда писать, если с узлом что-то случится. Тоже можно
   пропустить, но лучше настроить: иначе о проблемах вы узнаете, только заглянув в панель.
5. **Завершение** — панель закрывается паролем и вторым фактором.

## Шаг 3. Подключить устройства

В разделе «Кто подключён»:

1. впишите имя устройства латиницей — `phone-vadim`, `laptop-work`;
2. нажмите «Выдать доступ»;
3. для телефона — «QR» и сканирование в приложении WireGuard;
   для компьютера — «Скачать» и импорт файла.

В списке будет видно, кто на связи и сколько трафика прошло. Кнопка «Отозвать» мгновенно
лишает устройство доступа.

## Проверка, что всё работает

На устройстве с включённым туннелем откройте любой сервис «мой IP» — он должен показать
адрес вашего сервера, а не вашего домашнего провайдера.

В панели нажмите «Проверить выход»: она спросит у внешнего сервиса, каким адресом виден
сервер, и покажет результат.

## Если что-то пошло не так

* **Панель не открывается.** Проверьте, что вы указали `https://` и порт `8443`, и что
  хостер не режет порт файрволом.
* **Устройство подключилось, но интернета нет.** В панели нажмите «Проверить выход», затем
  «Ротация» — узел попробует починиться сам.
* **Забыт пароль панели.** Заведите учётку заново на сервере:
  `python3 /opt/vpn-panel/webpanel/setup_admin.py --label node1 --force`, затем
  `systemctl restart vpn-panel`.
* **Сервер перезагрузили.** Ничего делать не нужно: туннель и правила поднимаются сами.

## Обновление

Перезапустите ту же команду `bootstrap.py` — она обновит код и настройки, сохранив ключи,
клиентов и учётную запись панели.
