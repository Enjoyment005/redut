# Редут 1.14.0 — обновление сетевого ядра

Дата: 27 ноября 2026 года.

## Что изменилось

- sing-box обновлён с 1.11.7 до 1.14.5. Закреплены SHA-256 архива и бинарника Linux amd64.
- Установка и полное обновление используют типизированные DNS-серверы и действия маршрутизации `sniff` / `hijack-dns`; удалены устаревшие настройки.
- Миграция сохраняет действующий прокси, SOCKS5/HTTP, правила Telegram и настройки TUN. Повторная установка не добавляет дубликаты правил.
- DNS Rescue генерирует конфиг нового формата для прямого и проксируемого DoH.
- Старые резервные конфиги выходов сохраняются; для отката создаётся совместимая копия с отдельной контрольной суммой операции.
- Конфиг проверяется новым ядром до активации. Установщик сохраняет прежние бинарник, конфиг и boot-скрипт и восстанавливает их при обнаруженной ошибке.
- Деплой только агента на старое ядро блокируется до полного обновления.

## Обновление

Используйте штатное обновление РЕДУТа. При замене ядра будет короткий перерыв VPN.
Резервные копии ядра находятся в приватных каталогах `/etc/sing-box/.core-before.*`.
При аварийном отключении питания может понадобиться восстановление этой пары вручную.
Нестандартные устаревшие DNS-конфиги требуют явной миграции; установщик не удаляет неизвестные опции.

Интеграция ZenXNet и импорт подписок отложены на отдельный выпуск.

## Проверки

Полные canonical и public наборы на Python 3.12: по 1541 тесту, OK, по два платформенных пропуска. Публичный набор в изолированном Debian 13 / Python 3.13: 1541 тест, OK, семь пропусков по возможностям окружения. Release tooling: 77 тестов, OK.

Настоящий sing-box 1.14.5 проверил свежий и мигрированный конфиги, SOCKS5/HTTP и оба режима DNS Rescue. В изолированной проверке через loopback прошёл HTTP-трафик через SOCKS5 и HTTP с авторизацией. Проверены повторная установка, сохранность выбранного выхода, отказ до замены при неверном конфиге и восстановление пары после искусственного сбоя. Старый 1.11.7 принимает конфиг, который формирует прежний установщик при откате.

Независимый аудит завершён: исправлен пропуск проверки ядра в прямом запуске setup_panel.py; повторная проверка — PASS. Проверены синтаксис, публичная сборка без секретов и dry-run деплоя.

Живая установка на рабочий узел и проверка TUN/маршрутов на нём не выполнялись.
