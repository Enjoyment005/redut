# Почта и уведомления

При новой установке РЕДУТ автоматически подготавливает **AtomicMail**.
Введите свой email в мастере и подтвердите PIN из письма. Пароль личной почты
не нужен; отдельный почтовый сервер на VPS не устанавливается.

```bash
bash setup.sh          # AtomicMail по умолчанию
bash setup.sh --smtp   # свой SMTP
```

Для SMTP мастер запросит сервер, порт, логин и пароль, затем проверит адрес PIN-кодом.
Поддерживаются TLS на порту 465 и STARTTLS, обычно на порту 587.

- Почта общая для обоих контуров.
- Обновление и переустановка сохраняют текущие настройки и ящик.
- Если почта недоступна, повторите проверку или пропустите этот шаг. VPN продолжит
  работать; после пропуска email-уведомления отключены.
- При неизвестном результате отправки автоматического повтора нет. Если письмо
  пришло, введите PIN; новый код можно запросить кнопкой через минуту.

Храните `/etc/vpn-panel/secrets.json` вместе с конфигурацией в защищённой резервной
копии. Файл содержит ключ почты: права `0600`, доступ только администратору.
Лимиты отправки определяет AtomicMail.

При установке через `install/bootstrap.py` свой SMTP выбирается флагом `--smtp`,
через `install/setup_panel.py` — `--mail-transport smtp`.
