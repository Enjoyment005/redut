# Редут 1.13.5 — простой каталог и автоматика трёх провайдеров

Дата: 8 сентября 2026 года.

Раздел «Деньги» упрощён до одной формы: выбрать провайдера, предложение и купить.
Каталог загружается один раз; повторная загрузка стран в другой вкладке не нужна.
Ручные операции ProxyWing и ProxyLine не требуют отдельной настройки USD-бюджета.

## Что изменилось

- **ProxyWing:** только «Датацентр IPv4» и «ISP прокси», страны из предложений
  выбранного типа, месячная покупка с полной ценой пакета. Продление действующего
  заказа — один выбор срока 1/3/6/12 месяцев с точной ценой, без лишних подтверждений.
- **ProxyLine:** покупка из каталога, ручное и автоматическое продление через API.
  Исправлены типы новых заказов, допустимые сроки и разбор ответов со списком прокси.
  Если API не возвращает сумму списания, журнал показывает «сумма в кабинете».
- **Автопродление:** у всех трёх провайдеров выбирается точное действующее подключение,
  проверяются его работоспособность и свежий срок у провайдера. По умолчанию продление
  выполняется за 3 дня; ProxyWing продлевает весь текущий заказ один раз.
  Разрешение новых покупок и их бюджеты не блокируют включённое автопродление.
- **Автопокупка:** пополнение и создание резерва используют PROXY6, ProxyLine и
  ProxyWing, реальное наличие, выбранную стратегию и историю стабильности провайдера.
  RUB и USD не смешиваются. Настройки автоматических покупок сохраняются.
- **Защита оплаченного результата:** потеря ответа не запускает ещё одну покупку
  у другого провайдера. Уже оплаченные IP загружаются без повторной оплаты и
  проверяются перед использованием. Исправный резерв сохраняется при смене стратегии;
  старое задание не перезаписывает вручную закреплённый канал.
- **Установка и обновление:** новые модули включены в установщик и deploy;
  настройки владельца сохраняются. Основные публичные руководства теперь собираются
  из канонических исходников вместе с кодом.

## Проверки и границы выпуска

Полный канонический набор после исправлений: **1390 тестов, OK, 3 платформенных пропуска**.
Проверены 33 новые регрессии денежной автоматики, четыре набора JavaScript панели,
установка и повторная установка, автономный deploy dry-run. Независимый финальный
аудит завершён; подтверждённые замечания исправлены.

Публикация проходит штатный release.py: полные тесты канонического и публичного
деревьев, проверку секретов, Linux CI кандидата/main/тега и внешнюю проверку Release
и архива. Сведения о ранее протестированной публичной копии не заменяют эти проверки.

Выпуск **без серверной приёмки полной версии (`--untested`)**. Ранее ручной поток
ProxyWing проверен владельцем на VADIM; итоговые изменения всех провайдеров и автоматики
на узел ещё не установлены. Платные операции для проверки не выполнялись.
Обычный deploy dry-run ограничен отсутствием локального профиля `node2`;
автономная проверка выполнена без SSH. Автоматический DNS Rescue остаётся выключенным.

Неизвестный результат оплаты без сохранённого ответа требует сверки. Отсутствие
идемпотентности в API не подменяется автоматическим повтором списания.
