# РЕДУТ 1.15.0

ZenXNet, второй контур и простая настройка почты. Ядро — sing-box 1.14.5.

## Что нового

- **ZenXNet:** добавление по ссылке подписки, выбор сервера вручную или автоматически.
- **Второй контур:** отдельная цветная вкладка через «+», собственные выход, DNS и устройства. Доступ выдаётся и переносится явно; списки контуров не смешиваются.
- **DNS каждого контура:** DNS провайдера или Cloudflare через прокси. Во втором контуре доступен строгий режим без российских исключений и аварийного прямого выхода; у каждого режима есть краткая подсказка.
- **Геолокация:** IP2Location.io с резервом ipwho.is и общим кэшем. Название локации провайдера отделено от страны, которую определили базы.
- **Очистка следов:** исправлен подсчёт удалённых данных. Оба контура показывают общую статистику узла без удвоения.
- **AtomicMail по умолчанию:** новая установка готовит отправителя автоматически; пользователь вводит только email и PIN. Свой SMTP включается флагом `--smtp`, уведомления работают для обоих контуров.

## Перед обновлением

Текущие устройства, почта и DNS сохраняются. Второй контур и новые режимы DNS включаются отдельно.
Сохраните резервную копию конфигурации и `secrets.json` — в нём находятся ключи доступа, включая почту.

Поддерживаются два контура и одна подписка ZenXNet на узел; второй контур работает с ZenXNet. Формат подписки — VLESS TCP / REALITY / Vision. Новый узел может занять слот подписки; продление выполняется у провайдера.

Строгий режим передаёт имена сайтов прокси, но не гарантирует страну его DNS. Собственный DoH приложений и трафик вне VPN остаются вне контроля РЕДУТа; TXT, MX и SRV в строгом режиме недоступны.
При отказе AtomicMail настройку почты можно повторить или пропустить — VPN продолжает работать без email-уведомлений.
