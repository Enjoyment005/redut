# Редут 1.13.7 — автоплатёж только услуги боевого прокси ProxyWing

Дата: 5 октября 2026 года.

## Что изменилось

- В панели добавлен отдельный переключатель «Автоплатёж ProxyWing для боевого прокси»; CLI: `vpn-agent provider-auto-renew --enable`, `--disable`, `--status`.
- Режим opt-in: при установке и обновлении выключен по умолчанию. Включение разрешено только для здорового однозначного боевого подключения, активной месячной singleton-услуги и `proxywing_months=1`.
- Редут связывает точный заказ с услугой через `service_id`, проверяет ответ провайдера отдельным GET и сохраняет собственное владение переключателем в SQLite. Ранее включённый чужой флаг не присваивается и не отключается.
- При смене боевого прокси Редут отключает собственный автоплатёж прежней услуги. Неудавшаяся очистка сохраняется для повторной сверки и не блокирует аварийное восстановление VPN.
- При режиме провайдера исключено дополнительное прямое продление. Устаревший cron-снимок не отменяет отключение владельцем; неизвестный исход запроса не запускает повторную финансовую операцию.
- Исправлен порядок доставки transport dependency перед адаптером. Ошибки вспомогательного чтения и финансового журнала не останавливают apply/rollback.

## Денежные границы

ProxyWing оплачивает продление услуги из своего баланса по своему billing cycle, **вне локальных лимитов Редута**. PUT переключателя сам по себе не оплачивает счёт и не доказывает продление. Публичный API адресной оплаты произвольного ранее выставленного invoice не подтверждён; для такого счёта может понадобиться кабинет провайдера. Общие услуги с несколькими прокси не включаются.

## Проверки

Оба полных локальных набора: по 1529 тестов, OK, по два платформенных пропуска. Release tooling: 71 тест, OK. Независимый аудит воспроизвёл пять дефектов первого кандидата; исправления подтверждены отдельным bounded correction round, PASS. Проверены реальные промежуточные импорты последовательной доставки.

По отдельному разрешению владельца обновлён рабочий узел с проверенной резервной копией и восстановлением. Сохранены пользовательская конфигурация, секреты, WireGuard и cron; VPN не перезапускался. В живой проверке после включения автоплатежа точной боевой услуги провайдер автоматически погасил её renewal-сценарий: наблюдались оплаченный счёт, списание 1,80 USD и перенос срока на следующий месяц при прежнем IP. Дополнительный extend не отправлялся. Этот наблюдавшийся результат не является обещанием немедленной оплаты любых старых счетов при включении переключателя.
